A one-picture meme about AI agents building games and apps, built for [make.fun](https://make.fun)'s "Meme Sprint: AI Agents Ship Games" bounty. A proud little robot agent ships 12 games in one day — and every single one of them is Snake, just renamed twelve times.

## The joke

The boast on top, the punchline at the bottom, twelve identical snake posters in between: SNAKE, SNEK, SNAKE 2, SNAKE 2077, SUPER SNAKE, SNAKE REMASTERED, SNAKE ROYALE, SNAKE 64, SNAKE 3D, SNAKE ONLINE, SNAKE GOTY, THE SNAKENING. The agent's heroic shipping spree collapses into one punchline — they're all Snake.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only) copies the bundled `meme.png` to `/output/entry.png` — or to `$OUTPUT_PATH` when that is set — and refuses to write anything outside the gate: a whole PNG, at most 1 MiB and 1024 by 1024 pixels. The copy is byte-for-byte, so every run writes the same file. The meme itself is 1024×1024 and about 323 KiB.
